# Автопилот YouTube Shorts — анализ проекта (blueprint)

> **Обновление 27.10.2026 (после анализа):** канал переведён на американскую аудиторию: весь
> текст и хуки на английском, озвучка — бесплатный edge-tts (вместо Gemini TTS) с субтитрами по
> словам, публикация по America/New_York. Добавлен дашборд VidAuto Studio (http://localhost:8000).
> Стоимость ролика теперь ≈ $0.26 (без видео-хука) / ≈ $1.02 (с ним). Замечания ниже про русский
> язык и `hookscore.py` для английских роликов больше не актуальны: скрипт настроен именно на
> английский. Актуальная инструкция — файл «VidAuto — инструкция от А до Я.docx».

Дата проверки: 27.10.2026. Все цены и названия моделей сверены с официальными страницами
Google в этот день (ссылки внизу). Цены Google меняются — перед запуском откройте страницу
цен ещё раз.

## 1. Вердикт в одну строку

Идея рабочая, но в исходном тексте устарели **4 факта из 7**. Если собирать по нему
буквально, сломаются генерация картинок и видео, а бюджет «десятки роликов с видео-хуком
на $10» не сходится. Ниже исправленная схема, и по ней собран готовый проект `yt-autopilot/`.

## 3. Итоговая архитектура (то, что собрано)

```
Windows 11 → Docker Desktop
 ├─ контейнер n8n (http://localhost:5678)        ← расписание, загрузка на YouTube
 │    1. Schedule (каждый день) / ручной запуск
 │    2. POST http://worker:8000/produce   ───────┐
 │    3. GET  /files/<job>/final.mp4 (скачать)    │
 │    4. YouTube: Upload (private)                │
 │    5. YouTube API: status (время + AI-метка)   │
 └─ контейнер worker (Python + FFmpeg)  ◄─────────┘
      a. Gemini 3.8 Flash → тема, 5 хуков по 21 формуле из hooks.json, сцены, 5 заголовков
      b. hookscore.py (ваш skill yt-script) → выбирает лучший хук
         title.py   (ваш skill yt-package) → выбирает лучший заголовок
      c. Gemini 3.8 Flash TTS → озвучка каждой сцены
      d. Flash-Lite Image → вертикальные картинки (9:16)
      e. (опция) Omni Flash → живое видео только для хука
      f. FFmpeg → зум/панорама, склейка, динамические субтитры, музыка → 1080×1920 mp4
```

Почему рендер вынесен в отдельный контейнер, а не сделан внутри n8n: в n8n 2.x узел
Execute Command по умолчанию выключен, а в официальном образе n8n нет FFmpeg. Отдельный
сервис проще, безопаснее и проверяется сам по себе (адрес `/health`).

## 4. Стоимость одного Shorts (≈45 с, 7 сцен), цены до 31.12.2026

| Шаг | Модель | Цена | На 1 ролик |
|---|---|---|---|
| Сценарий | gemini-3.8-flash | $0.75 / $3.75 за 1M токенов | ≈ $0.02 |
| Озвучка | gemini-3.8-flash-tts | $9 за 1M аудиотокенов | ≈ $0.01 |
| 7 картинок | gemini-3.1-flash-lite-image | $0.0336 за шт. | ≈ $0.24 |
| Видео-хук (опция) | gemini-omni-1.1-flash | ≈ $0.10 за сек | ≈ $0.80 (если ~8 с) |
| Рендер, n8n, загрузка | ваш ПК, YouTube API | $0 | $0 |
| **Итого** | | | **≈ $0.27** без видео / **≈ $1.03** с видео (тогда картинок 6, а не 7) |

* Omni берёт деньги за весь сгенерированный клип, а в ролик идут только 3–5 секунд хука.
  Поэтому видео-хук — самая дорогая часть на секунду результата.
* У картинок и видео **нет бесплатного тарифа**, поэтому к проекту надо подключить
  оплату (billing). Как только оплата подключена, платным становится весь проект, включая
  текст и озвучку. Это копейки, но учтите.
* С 01.01.2027 цены на текст и TTS удваиваются. На итог это почти не влияет, основную
  сумму дают картинки.
* «Главный секрет экономии» из исходника верен по сути: картинки с движением камеры в
  4–30 раз дешевле видео. В проекте видео-хук выключен по умолчанию
  (`USE_VIDEO_HOOK=false`). Включайте его для отдельных роликов.

## 5. Риски и как они закрыты

| Риск | Что будет | Что сделано |
|---|---|---|
| Политика YouTube «inauthentic content» (с 15.07.2025): однотипные слайдшоу с похожей озвучкой не монетизируются | Канал не примут в YPP или снимут с монетизации | По умолчанию `AUTO_PUBLISH=false`: ролик загружается **приватным**, вы смотрите его и публикуете сами. Полный автопилот включайте после 2–3 недель проверки. Каждый ролик идёт по новой теме, а история тем хранится, чтобы темы не повторялись |
| Не отмечен ИИ-контент | Нарушение правил раскрытия ИИ-контента | Шаг 5 в n8n ставит `containsSyntheticMedia=true` |
| Токен YouTube протухает через 7 дней | Загрузка падает на второй неделе | В инструкции: перевести экран согласия OAuth в режим «In production» |
| ПК спит ночью | Расписание не срабатывает | В инструкции: настройка электропитания и автозапуск Docker Desktop |
| `hookscore.py` настроен на английский | Для русских хуков реально работают только оценки «конкретика» и «краткость» | Хуки всё равно пишутся по 21 формуле, скрипт используется как фильтр. Ограничение описано в инструкции |
| `~/.claude/youtube/voice.md` — незаполненный шаблон | Сценарии звучат безлико | Пока шаблон не заполнен, worker его не использует. В инструкции есть шаг «заполнить» |
| На Windows `hookscore.py` / `title.py` / `swipe.py` падают на кириллице (нет `encoding="utf-8"` в `open`) | Локальный запуск skills на русском ломается | В Docker (Linux, UTF-8) проблемы нет. Отдельно: правка из 4 строк в skills |
| Перерасход | Счёт больше ожидаемого | Предоплата без автопополнения + месячный лимит трат в AI Studio (Spend → Monthly spend cap). Бюджет в Cloud Billing только присылает письма |
| Ночной сбой никто не заметил | Пропущенный день | Утром проверять n8n → Executions; позже — Error Workflow с уведомлением в Telegram/Gmail |
| API-ключ утечёт | Чужие траты | Ключ лежит только в `.env`, его видит только worker. Порты открыты только на `127.0.0.1` |
| TikTok | Без аудита приложения TikTok API постит только приватно | Вне рамок v1. Добавляется отдельной веткой n8n позже |

## 6. План шагов (direct mode, без git)

| Шаг | Что | Зависит от | Проверка | Откат |
|---|---|---|---|---|
| 1 | Docker Desktop + WSL2 | — | `docker run hello-world` | Удалить Docker Desktop |
| 2 | Ключ Gemini + billing + бюджет-алерт | — | `/health` показывает `gemini_key: true` | Удалить ключ в AI Studio |
| 3 | Распаковать `yt-autopilot`, заполнить `.env` | 1 | `docker compose config` без ошибок | Удалить папку |
| 4 | `docker compose up -d --build` | 3 | `localhost:5678` открывается, `localhost:8000/health` → `ok` | `docker compose down` |
| 5 | Тест без денег: `MOCK=true` | 4 | В `data/jobs/*/final.mp4` появляется ролик | — |
| 6 | Google Cloud: YouTube API + OAuth | — | В n8n credential показывает «Connected» | Удалить OAuth-клиент |
| 7 | Импорт workflow в n8n, привязка credentials | 4, 6 | Ручной запуск в режиме MOCK → приватное видео на канале | Удалить workflow |
| 8 | Боевой прогон: `MOCK=false` | 2, 7 | Настоящий ролик, приватный, с AI-меткой | Удалить видео в Studio |
| 9 | Расписание + электропитание + (позже) `AUTO_PUBLISH=true` | 8 | Ролик появляется утром сам | Выключить workflow |

Шаги 2 и 6 можно делать параллельно с 1/3/4: это клики в браузере, они не зависят от Docker.
