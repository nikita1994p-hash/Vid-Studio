# 1. Что это и как работает

Vid Studio (раньше называлась VidAuto) сама делает короткие вертикальные ролики (Shorts) на английском для зрителей из США: серия «365 Businesses That Make Money» — один реальный бизнес в каждом ролике, со стоимостью запуска, прибылью, подвохом и первым шагом. Папка проекта, кнопки .bat и схема в n8n по-прежнему называются VidAuto — это одно и то же. Каждый ролик проходит 6 шагов — они же видны в Студии:

| Шаг | Что происходит | Чем делается | Цена |
| 1. Script & hooks | Бизнес дня, 5 хуков по 21 формуле (у каждого своя фраза-петля в конце), сценарий по вашим правилам «хук → середина → развязка → петля», 5 заголовков. Хуки оцениваются по правилам Shorts; если лучший слабее 55 баллов, строгий редактор переписывает их (до 3 раундов). Номер серии ставится сам. Длинную историю ИИ может разбить на 2–3 части. **Если включён выбор хука, ролик здесь останавливается и ждёт вас** (раздел 8.2) | Gemini Flash (бесплатный тариф) + hookscore_shorts.py, title.py, voice.md, script_rules.md | бесплатно |
| 2. Fact check | Второй, независимый запрос к ИИ проверяет каждую цифру сценария до озвучки. Сомнительное помечается (или исправляется — по настройке). Затем проверяются промпты картинок: убирается то, что ИИ рисует с дефектами | Gemini (бесплатный тариф) | бесплатно |
| 3. Voice-over | Озвучка выбранным голосом (язык, пол, скорость, тон) + точное время каждого слова | edge-tts (Microsoft) | бесплатно |
| 4. Images & video | AI-картинка на каждую сцену, сверху плашка «BUSINESS #N» и главная цифра. Если лимит FLUX кончился — настоящее фото, если и его нет — карточка с цифрой | FLUX.1 schnell (Cloudflare) → Openverse → карточки | бесплатно |
| 5. Editing | Склейка с движением камеры, субтитры по словам, свуш, музыка → MP4 1080×1920. Последний кадр совпадает с первым — ролик зациклен. Плюс обложка с крупной цифрой | FFmpeg на вашем ПК | бесплатно |
| 6. Publish | YouTube, TikTok, Instagram, страница Facebook, Threads (X — пока не подключён) — на выбранные аккаунты, с отметкой «создано ИИ» | n8n + ваши входы на странице Accounts | бесплатно* |

* X API платный: оплата за каждый запрос, около $0.015 за пост (раздел 10.7).

✅ Итого ролик стоит $0. Ролик с картинками FLUX делается за 5–10 минут (почти всё время — сценарий, проверки и переписывание хуков у перегруженного Gemini).

# 5. Ниша: что выбрано и почему

✅ 365 Businesses That Make Money — «скучные» реальные бизнесы (торговые автоматы, прачечные, мойка давлением, вывоз мусора, аренда надувных батутов), которые тихо делают обычных людей богатыми. В каждом ролике: сколько стоит запуск, сколько приносит в месяц, в чём подвох и первый шаг.

- «Скучные бизнесы» — устойчивый вирусный тренд: неожиданно и проверяемо.
- Финансы — одна из самых дорогих тематик для рекламы на YouTube: высокий доход с длинных роликов позже.

## Риски и как они закрыты

- Обещания дохода (YouTube и FTC США): только «about / typically», без гарантий; в описании — «Numbers are typical US estimates; results vary. Not financial advice.»
- Выдуманная статистика: запрет в правилах серии и сценария, проверка фактов до озвучки.
- Однотипный контент: новый бизнес в каждом ролике, история снятых бизнесов защищает от повторов.
- ИИ-контент: отметка «создано ИИ» (Settings → Publishing → Mark as AI-generated) ставится на YouTube и TikTok. Не выключайте её: у роликов фотореалистичные картинки и синтетический голос, а без отметки YouTube и TikTok могут сами поставить метку, удалить ролик или ограничить монетизацию. На охваты метка, по словам YouTube, не влияет.

Поменять нишу: Студия → Settings → Content (ниша, аудитория, название серии, правила серии, плашка, начало заголовка).

# 6. Как строится сценарий

Перед каждым роликом ИИ читает правила сценария: Студия → Settings → блок Script rules. По умолчанию:

| Часть | Что в ней |
| Хук (3–5 с) | Смелое утверждение или вопрос на реальных цифрах бизнеса |
| Вступление | Что это за бизнес простыми словами: кто платит и за что |
| Середина | Каждая сцена отвечает на вопрос прошлой и открывает новый: сколько стоит запуск → откуда деньги → что остаётся → подвох |
| Развязка | Первый шаг как действие на этой неделе, целым предложением |
| Петля | Последняя фраза перетекает в хук; картинка в конце отъезжает ровно к первому кадру — при повторе склейки не видно |

Строки, начинающиеся с #, — заметки для вас, ИИ их не видит. Кнопка Restore default возвращает исходные правила. Изменения действуют со следующего ролика.

## Части 1/2/3

Если бизнесу нужно больше ~60 секунд, ИИ сам делит историю на 2–3 ролика: «Business #7 (Part 1/3): …», плашка «BUSINESS #7 · PART 1/3». Часть 1 заканчивается анонсом части 2. Из Студии все части делаются подряд; по расписанию n8n — по одной в день. Максимум частей — Settings → Content → Split long stories into up to N parts (1 = никогда не делить). Петлю можно выключить там же (Loop ending).

## Свои формулы хуков канала

Файл data\channels\<канал>\hooks.json: skip — какие общие формулы не использовать (у канала: the-statistic и формулы для блогеров), hooks — свои формулы, их ИИ видит первыми. У «365 Businesses»: The Catch First, The Weekend, Boring vs Glamorous, The One Job, Would You, Under a Grand, Season Now. Плюс в промпт попадают хуки последних 8 эпизодов — ИИ не повторяет их цифры и начало.

## Оценка хуков для Shorts

Каждый из 5 хуков получает оценку от 0 до 100 по пяти признакам, которые важны в первые 2–3 секунды Shorts:

| Признак | Что проверяется |
| Цифра | Конкретное число: цена, доход, количество (числа словами тоже считаются) |
| Ставка | Деньги, которые можно заработать или потерять |
| Любопытство | Открытый вопрос или разрыв, который хочется закрыть |
| Первые пять слов | В них уже есть цифра, бизнес или «you» |
| Длина | 8–18 слов — успевает прозвучать за 3–5 секунд |

Итог: 70 и выше — STRONG, 55–69 — WORKABLE, ниже — WEAK. Если лучший хук слабее цели, ИИ переписывает слабые хуки, а строгий редактор отбраковывает варианты, которые уходят от темы, выдумывают цифры, звучат неестественно или ломают фразу-петлю. Без выбора хука в ролик идёт лучший прошедший проверку хук; с выбором — тот, который отметили вы. Отчёт по раундам — на вкладке Script ролика.

| Settings → Content | Что значит |
| Hook score to aim for | Цель, по умолчанию 55. Выше цель — дольше делается ролик (каждый раунд 1–3 минуты) |
| Hook scorer | shorts — оценка для Shorts (рекомендуется); skill — старая оценка из скилла yt-script |
| Hook rewrite rounds | Сколько раундов переписывания, 0–4 (по умолчанию 3; 0 — выключить) |
| Wait for me to pick the hook and title… | Ролик ждёт вашего выбора хука и заголовка (раздел 8.2). Сейчас включено |
| Words in the whole body | Длина ролика: около 2,6 слова в секунду. Канал: 65–80 слов (ролик ~30–35 с) |
| Longest hook, words | Канал: 14 |
| Where the episode tag goes in the title | end — «$300 a Yard Raking Leaves (Business #9)»: в ленте первыми видны суть и цифра |
| Show 'Tomorrow #N…' | На последней сцене под плашкой серии: «TOMORROW #10: CHRISTMAS TREE LOT» — следующая тема из очереди. Причина подписаться |
| Post the video's question… | После загрузки на YouTube Студия оставляет первым комментарием вопрос зрителям. Закрепить его API не даёт: YouTube Studio → Комментарии → ⋮ → Закрепить |

💡 Высокий балл не цель сам по себе: редактор не пропустит «красивый», но неправдивый хук. Поэтому иногда лучший хук набирает 56–63 балла — это нормально.

| Карточки | Анимированный фон + цифра | Если не нашлось ни картинки, ни фото |
| Gemini Pro вручную | Ваша картинка + цифра поверх | Кнопки ниже, ~1 минута на картинку |

Стиль картинок (например «photorealistic, cinematic light» или «3D cartoon») — Settings → Picture → Picture style.

⚠ Если в Telegram пришло «⚠ FLUX pictures stopped working», значит, дневной лимит кончился (обычно из-за большого числа тестовых роликов). Ролик всё равно делается — с фото или карточками с цифрами. Картинки у готового ролика можно перерисовать позже или заменить вручную.

💡 Модель FLUX в Cloudflare принимает только текст запроса и число шагов. Размер всегда 1024×1024, ролик обрезает картинку до вертикали 9:16.

## Если картинок не хватает

- Второй бесплатный аккаунт Cloudflare — не вариант: это против правил Cloudflare, можно потерять оба аккаунта.
- Шаги FLUX уже снижены до 4 — для модели schnell это достаточно, картинка практически та же.
- Не делайте лишних тестов. Тестовый режим (Test mode) не тратит Gemini, но если источник картинок — FLUX, картинки FLUX он всё равно может заказать. A/B-версии тоже тратят картинки, если включено Settings → Variants → New pictures for versions.
- Cloudflare Workers Paid — $5 в месяц, когда каналов станет много: дальше примерно полцента за ролик.

## Проверка промптов картинок

Перед FLUX второй запрос к ИИ просматривает описание каждой картинки и переписывает то, что нейросеть рисует с дефектами: руки и пальцы крупным планом, надписи и вывески, толпы, экраны с текстом. Что исправлено, видно на вкладке Script ролика (было → стало). Выключить: Settings → Picture → Check picture prompts before FLUX.

## Заменить картинку вручную

1. Студия → ролик → вкладка Script & hooks → Scenes.
2. У сцены 📋 Copy prompt for Gemini → вставьте в https://gemini.google.com → скачайте картинку.
3. У той же сцены 🖼 Replace picture → выберите файл. Повторите для других сцен.
4. 🎬 Re-render video — через ~40 секунд ролик пересоберётся.

💡 Сцена «Loop ending» всегда показывает картинку хука — чтобы конец совпадал с началом.

## 8.1. Версии (A/B-тест)

Каждая версия — та же тема и те же факты, но другой хук (со своей петлёй), другой заголовок, голос, музыка, цвет субтитров и при желании новые картинки. Версии получают буквы A, B, C…

- Без выбора: Студия сама берёт следующий по оценке хук и другой заголовок.
- С выбором: в карточке выбора хука под версией A есть строки **Version B, C…** — у каждой свой список хуков с баллами и своё поле заголовка с подсказками. Студия заранее подставляет то, что выбрала бы сама; можно поменять.
- Для готового ролика: блок **Versions for A/B testing** на его странице → сколько версий → галочка **«Let me pick the hook and title for each version»** → Make versions.

⚠ Не публикуйте почти одинаковые ролики подряд на один канал: YouTube считает это повторяющимся контентом и может ограничить канал. Хорошая схема: разные версии — на разные платформы или на YouTube с разницей в несколько дней.

## 8.2. Выбор хука и заголовка

Когда выбор включён, ролик после проверенного сценария получает статус **«Pick a hook»** и ждёт сколько угодно. В Telegram приходит «✍ Pick the hook and title» со ссылкой — она открывается и с телефона.

1. Откройте ролик (по ссылке из Telegram или в Студии → Content).
2. Выберите один из 5 хуков — рядом баллы и формула; у каждого своя фраза-петля.
3. Выберите заголовок или впишите свой. Номер серии («Business #N:») подставится сам.
4. Если нужны A/B-версии — выберите хук и заголовок для каждой.
5. Нажмите **Make the video** (или «Make the video and N version(s)»).

Дальше Студия делает озвучку, картинки и монтаж уже для вашего хука. Если это утренний ролик, после сборки он сам уходит в n8n и публикуется на платформы из Settings → Publishing → Where the daily n8n run posts — так же, как без выбора.

| Настройка | Где | Что делает |
| Ожидание каждого ролика | Settings → Content → Wait for me to pick the hook and title after the script (the daily video too; it is posted once made) | Включено: и утренний, и новые ролики ждут выбора. Выключено: Студия выбирает сама, утренний ролик публикуется сразу |

# 11. Публикация и n8n

## 11.1. n8n

✅ Вход владельца создан, workflow «VidAuto: Make & Publish» опубликован — ежедневный запуск в 11:00 по Киеву включён. После любых правок в n8n — снова Publish.

```
Запустить вручную ─┐
Каждый день в 11:00┴→ Сделать ролик → Куда постить ─┐
Кнопка из Студии ──────────────────────────────────┴→ По платформам → Опубликовать
```

В n8n ключи соцсетей не нужны: входы хранятся в Студии, n8n только решает, когда и куда публиковать. Ошибка на одной платформе не останавливает остальные. Журнал — слева Executions. Если утренний ролик ждёт выбора хука, n8n в 11:00 ничего не публикует — после вашего выбора Студия сама передаёт готовый ролик в n8n.

🔐 Студия выполняет команды n8n (сделать ролик, опубликовать, сообщить об ошибке) только с секретным токеном: n8n отправляет его в заголовке `x-internal-token`, а берёт из `INTERNAL_TOKEN` в .env. В блоках n8n он записан как `{{ $env.INTERNAL_TOKEN }}` — сам токен в схемах не хранится. Добавляете в n8n новый блок HTTP Request к `http://worker:8000/…` — включите Send Headers и добавьте тот же заголовок, иначе Студия ответит 403 forbidden.

## 11.2. Опубликовать ролик вручную

1. Студия → ролик → блок Publish.
2. Галочки у нужных платформ (рядом видно, на какой аккаунт пойдёт ролик).
3. Режим: Private / only me, YouTube: schedule (время из Settings → Publishing), Public now.
4. Publish. Статус каждой платформы: queued → uploading… → posted ✓ со ссылкой, failed с текстом ошибки или interrupted (если Студию перезапустили во время публикации — нажмите Publish снова).

💡 Publish на ролике, уже загруженном на YouTube, меняет его доступ (например, приватный → публичный), а не загружает копию. Если ролик удалили в YouTube Studio, следующий Publish загрузит его заново. У Instagram, Facebook и X нет приватного режима: «Private» там всё равно публикует открыто. Галочка Post directly from the Studio (without n8n) публикует без n8n.

## 11.3. Ежедневный запуск в 11:00

Каждый день в 11:00 по Киеву n8n запускает ролик для каждого канала с отметкой «Make a video every day at 9:00» (так галочка называется в Студии; само время запуска задаёт n8n) (раздел 21) — по очереди, по 6–10 минут на канал. Тема — следующая из очереди Topics.

| Шаг | Что происходит сейчас |
| 11:00 | Сценарий и проверки, затем ролик ждёт выбора хука («✍ Pick the hook and title» в Telegram). Час запуска меняется только в n8n (блок «Каждый день в 11:00»), а не в Publish time |
| После выбора | Озвучка, картинки, монтаж, обложка (5–10 минут) |
| Публикация | YouTube, TikTok (приватно), Instagram, Facebook, Threads. На YouTube — публично сразу (AUTO_PUBLISH включён) |
| Telegram | «✅ Ready…» и «📤 …» по каждой платформе со ссылками |

| Настройка | Где | Сейчас |
| Куда публикуется | Settings → Publishing → Where the daily n8n run posts | youtube,tiktok,instagram,facebook,threads |
| Публично на YouTube | Settings → Publishing → YouTube: publish on schedule (AUTO_PUBLISH) | on |
| Время и пояс | Settings → Publishing → Publish time, Publish time zone | 11:00, Europe/Kyiv |

## 13.1 Очередь тем (Topics)

Студия → Topics — список бизнесов, которые ещё предстоит снять, по порядку. Ролик с пустой темой берёт первую тему из списка. Тема отмечается filmed только когда ролик готов.

## 13.2 Проверка фактов до озвучки

После сценария второй, независимый запрос к Gemini проверяет каждую цифру: реальны ли стоимость запуска, цены и прибыль для США, не названа ли одна вещь разными числами, не перепутана ли прибыль с выручкой. Результат — карточка Fact check на странице ролика.

| Settings → Content → Fact check | Что происходит |
| flag (по умолчанию) | Только помечает сомнительное и предлагает исправленную фразу |
| fix | Явные ошибки в сценах исправляются автоматически до озвучки. Хуки и ваш собственный сценарий не меняются |
| off | Без проверки |

⚠ В режиме flag в Telegram приходит «⚠ N doubtful figure(s) — check the Script tab before posting». При выборе хука вы видите сценарий до озвучки — это удобный момент проверить цифры.

## 13.5 Итоги A/B-тестов (A/B tests)

Студия → A/B tests. Когда минимум две версии выложены на YouTube, прошло 7 дней и у каждой 100+ просмотров, побеждает версия с самым высоким средним процентом просмотра; при равенстве — по просмотрам.

- Таблица теста: хук и его формула, голос, просмотры, % просмотра, среднее время, лайки, просмотры на других платформах. Победитель отмечен 🏆.
- Hook types и Voices — сводка по всем тестам; 💡 подсказка, какой тип хука выигрывает.
- С Settings → Variants → Use A/B winners when writing new hooks ИИ строит минимум 2 из 5 хуков на формулах-победителях.

# 19. Советы: что улучшить дальше

- Каждое утро при выборе хука смотрите на баллы, но выбирайте то, что сами бы досмотрели: через 2–3 недели A/B tests покажет, чей выбор лучше.
- Делайте 2–3 версии ключевых роликов и раз в неделю смотрите страницу A/B tests.
- Картинка хука — первые 2 секунды решают всё. Если FLUX-хук слабый, замените его через Gemini Pro.
- Читайте карточку Fact check первых 10–20 выпусков; если ложных тревог почти нет — включите режим fix.
- Скилл yt-viral раз в неделю — что заходит в нише; yt-retention после 10 роликов — где уходят зрители.
- Резервная копия папки data раз в месяц (там и ролики, и входы в соцсети).

| TikTok: пост приватный | Так и должно быть до проверки приложения TikTok (10.3) |

# 21. Аккаунты Студии и каналы

В Студию входят по почте и паролю, а внутри может быть несколько каналов. У каждого канала свои входы в соцсети, настройки, темы и ролики.

## 21.1. Первый вход

1. Откройте Студию — появится страница входа.
2. Вкладка Create account: почта и пароль (не короче 8 символов, не из простых вроде password123 и не совпадает с почтой). Под кнопкой — строка о согласии с Terms и Privacy Policy; возраст 18+ указан в них.
3. Почта из SUPERADMIN_EMAILS становится супер-админом и получает канал «365 Businesses That Make Money» со всеми роликами.
4. Остальные регистрируются сами и получают аккаунт без тарифа (21.7), а по ссылке-приглашению — сразу с тарифом.

# 22. Песочница: проверка перед обновлением

Песочница — копия Студии на `http://localhost:8001` со своими данными (папка data-sandbox) и своим входом. Новые функции сначала проверяются там, и только после вашего согласия обновляется настоящая Студия.

| Что | В песочнице |
| Публикация в соцсети | Выключена: Студия только пишет в журнал, куда отправила бы ролик |
| Telegram и фоновые задачи | Выключены |
| Gemini и FLUX | Настоящие — тест тратит те же бесплатные лимиты. Поэтому новый ролик в песочнице делается только с вашего разрешения |
| Новые картинки для версий | Выключены, чтобы тесты не тратили лимит FLUX |
| Двухэтапный вход | Не обязателен ни для кого (можно включить вручную для проверки) |
| Письма сброса пароля | Настоящие (та же почта из .env); ссылка ещё и пишется в журнал песочницы |

✅ Порядок обновлений: изменение → проверка в песочнице → ваше «Update the real Studio» → проверка, что в настоящей Студии ничего не делается и не публикуется → перезапуск → проверка, что Студия и публичный адрес работают.

# 23. Безопасность: вход, пароли, ключи

## 23.1. Двухэтапный вход (2FA)

После пароля Студия спрашивает 6-значный код из приложения на телефоне: украденного пароля мало, чтобы войти. Обязателен для супер-админа и владельца Студии (они управляют всеми аккаунтами), админы и пользователи включают его по желанию.

1. ☰ → 🔑 My account → Two-step sign-in → Set up two-step sign-in.
2. Google Authenticator → «+» → Scan a QR code и наведите камеру на QR в Студии. Если Студия открыта на том же телефоне: Enter a setup key, вставьте ключ под QR, тип Time based.
3. Введите 6 цифр, которые показывает приложение для Vid Studio → Turn on.
4. Появятся 8 запасных кодов → Copy → сохраните их вне телефона (менеджер паролей, распечатка, бумага в надёжном месте) → I saved them. Второй раз они не показываются.

Вход дальше: почта + пароль → код из приложения. Вместо кода можно ввести запасной — каждый работает один раз. Код из приложения тоже нельзя использовать дважды.

| Что | Как |
| Осталось мало запасных кодов (видно в My account) | My account → код из приложения → New backup codes. Старые коды перестают работать |
| Новый телефон, старый на руках | Google Authenticator на старом телефоне → ⋮ → Transfer accounts → Export → отсканируйте на новом. Или включите в приложении резервную копию в аккаунт Google |
| Код не подходит | На телефоне: Настройки → Дата и время → автоматически. Код меняется каждые 30 секунд — вводите свежий |
| Выключить 2FA (только админ или пользователь) | My account → код + пароль → Turn off. Супер-админ и владелец выключить не могут |

⚠ 5 неверных кодов подряд блокируют вход на 15 минут, как и неверные пароли.

## 23.2. Потеряли телефон

1. Запасной код есть: войдите почтой, паролем и запасным кодом вместо кода из приложения.
2. Привязать новый телефон. Пользователь или админ: My account → запасной код + пароль → Turn off, затем Set up заново уже с новым телефоном. Супер-админ или владелец: другой супер-админ или владелец нажимает ☰ → Users → 🔓 Reset 2-step, либо на этом ПК в папке проекта выполните команду ниже. При следующем входе Студия попросит настроить 2FA с новым телефоном и выдаст новые запасные коды.
3. Запасных кодов нет: только сброс админом (🔓 Reset 2-step) или та же команда на этом ПК. С чужого компьютера без доступа к этому ПК сбросить 2FA нельзя — так и задумано.
4. Если телефон украден: в Telegram с другого устройства → Settings → Devices → завершите сеанс потерянного телефона; при подозрении смените пароль Студии и пароль Google.

```
docker compose exec worker python auth.py reset-2fa ваша@почта
```

Сброс выключает 2FA и выходит со всех устройств; в Telegram → 🔐 Security приходит оповещение.

## 23.3. Забыли пароль

1. Страница входа → Forgot password? → почта аккаунта → Send me a reset link.
2. С vidstudio.support@gmail.com приходит письмо «Password reset request - Vid Studio» (если нет — проверьте спам).
3. Ссылка → новый пароль дважды → Set the new password. Если включён 2FA — потом ещё код.

| Правило | Зачем |
| Ссылка работает один раз и 30 минут; новая ссылка отменяет старую | Старое письмо в ящике бесполезно для чужого |
| Не больше 3 писем в час на аккаунт | Никто не завалит ваш ящик письмами |
| Ответ на странице одинаковый для любой почты | По странице нельзя узнать, у кого есть аккаунт |
| После сброса выходят все устройства, приходит письмо «Your password has been changed» с датой | Если пароль меняли не вы — сразу видно |
| Ссылка в письмах ведёт на публичный адрес Студии | Открывается и с телефона |

Правила пароля везде (регистрация, смена, сброс): не короче 8 символов; не из списка простых (12345678, password123, qwerty123…); не совпадает с почтой; не из 1–3 повторяющихся символов.

Без почты: админ → ☰ → Users → 🔑 Password.

## 23.4. Блокировка и защита от подбора

- 5 неверных паролей или кодов подряд — аккаунт заблокирован на 15 минут. Сброс пароля по почте снимает блок сразу.
- С одного адреса — не больше 20 попыток входа за 10 минут и 10 регистраций в час, дальше пауза.
- Оба случая приходят в Telegram → 🔐 Security.

## 23.5. Оповещения безопасности

Приходят админам в Telegram (тема 🔐 Security), одно оповещение одного вида — не чаще раза в час.

| Сообщение | Что значит | Что делать |
| 🔒 … locked for 15 minutes | 5 ошибок входа подряд | Если это не вы — кто-то подбирает пароль; пароль сложный — ничего |
| ⛔ … paused | С одного адреса слишком много попыток | Обычно бот; ничего |
| 👑 Role changed, пароль сменён, блок, удаление | Действие админа на странице Users | Проверьте, что это делали вы или ваш админ |
| 🔁 … reset the password | Сброс по ссылке из письма | Не вы — сбросьте пароль снова и проверьте почтовый ящик |
| 🔑 … signed in with a backup code | Вход запасным кодом | Не вы — у кого-то ваш пароль и коды: смените пароль, сделайте новые коды |
| 🔓 Two-step … off / reset | 2FA выключили или сбросили | Не вы — сразу смените пароль и включите 2FA |
| ✉ … e-mail could not be sent | Gmail не принял письмо | Проверьте SMTP_PASSWORD (23.6) |

## 23.6. Ключи и их замена

Все ключи — в .env (или в Студии), никогда не в чатах и не на GitHub. После правки .env — «Запустить VidAuto.bat». Порядок замены всегда один: создать новый → вписать → перезапустить → проверить → удалить старый.

| Ключ | Как заменить |
| CF_API_TOKEN (Cloudflare, картинки) | dash.cloudflare.com → профиль → My Profile → API Tokens → Create Token → шаблон Workers AI → Account Resources: ваш аккаунт, IP-фильтр не ставить, имя с датой (например «Vid Studio FLUX 2026-11») → скопировать в .env → перезапуск → после проверки удалить старый токен (⋮ → Delete). Заменён 04.11.2026; менять раз в год |
| SMTP_PASSWORD (почта) | Войти в vidstudio.support@gmail.com → myaccount.google.com/apppasswords (нужна включённая двухэтапная проверка Google) → новое имя → Create → 16 букв без пробелов в .env → перезапуск → удалить старый пароль на той же странице |
| INTERNAL_TOKEN (n8n ↔ Студия) | Любая длинная случайная строка в .env → «Запустить VidAuto.bat» (перезапускаются и n8n, и Студия). В n8n ничего менять не нужно |
| GEMINI_API_KEY | aistudio.google.com → Get API key → Create → .env → перезапуск → удалить старый |
| Токен Telegram-бота | @BotFather → /revoke → бот → новый токен → Студия → Settings → Notifications → Save → Send test |
| Ключи соцсетей (App keys) | В кабинете разработчика платформы → новый secret → Студия → Accounts → App keys → Save |

## 23.7. Что Студия делает сама

- Отвечает только по https на публичном адресе, с защитными заголовками: страницы нельзя встроить в чужой сайт, скрипты — только свои.
- Отклоняет действия, пришедшие со страниц чужих сайтов.
- Проверяет загружаемые файлы по содержимому и размеру (видео до 500 МБ, картинка до 20 МБ).
- Показывает пользователю только номер ошибки (ref …), подробности — в журнале.
- Адреса n8n закрыты с публичного адреса и требуют токен.
- ИИ воспринимает текст пользователей как материал, а не как команды; ссылки, почты, @-упоминания и телефоны, которые написал ИИ, вырезаются из заголовков, описаний, тегов и обложек.
- Хранит пароли, запасные коды и ссылки сброса только в виде отпечатков. Карта API (/docs) не показывается.
- Шрифт Inter лежит в самой Студии (static/fonts), а не грузится с серверов Google: IP посетителя никуда не уходит (GDPR). Сторонней аналитики и записи сессий нет.
